# Simulate Google Jobs Salary Display Differences

This example Python script simulates how job platforms like Google Jobs might display salary information differently across various markets. It demonstrates how the presence or absence of salary data, and its specific presentation, can vary based on country-specific practices, highlighting transparency differences as discussed in the article.

## Language

`python`

## How to Run

Save the code as main.py.
Run from your terminal: python main.py
